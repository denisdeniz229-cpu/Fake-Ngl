# Fake NGL - Anonim Mesajlaşma Platformu

Instagram'ın NGL uygulamasına benzer bir anonim mesajlaşma platformu. Kullanıcılar anonim mesaj gönderdiklerini düşünürken, admin panelinden gönderen kişinin Instagram kullanıcı adı ve mesajları görüntülenebilir.

## Özellikler

- ✅ Anonim mesaj gönderme arayüzü
- ✅ Admin paneli ile mesaj görüntüleme
- ✅ Harf harf mesaj takibi
- ✅ Zar tuşu ile rastgele soru önerileri
- ✅ 48 saatlik bağlantı süresi
- ✅ Profil görseli yükleme
- ✅ Özel kullanıcı adı ile bağlantı oluşturma

## Kurulum

1. Bağımlılıkları yükleyin:
```bash
npm install
```

2. Sunucuyu başlatın:
```bash
npm start
```

3. Tarayıcıda açın:
- Ana sayfa: `http://localhost:3000`
- Admin paneli: `http://localhost:3000/admin`

## Kullanım

### Bağlantı Oluşturma
1. Ana sayfada profil görseli yükleyin
2. Kullanıcı adı girin
3. Bağlantı oluşturun
4. Oluşturulan bağlantıyı paylaşın (örn: `ngl.link/kullanici_adi`)

### Mesaj Gönderme
1. Bağlantıya tıklayın
2. Mesajınızı yazın veya zar tuşuna basarak rastgele soru seçin
3. Gönder butonuna tıklayın

### Admin Paneli
- Kullanıcı adı: `Deno08`
- Şifre: `@3105_6`

Admin panelinden:
- Tüm bağlantıları görüntüleyebilirsiniz
- Mesajları ve gönderen kişileri görebilirsiniz
- Harf harf yazım geçmişini takip edebilirsiniz
- Zar ile yazılan mesajları işaretli görebilirsiniz

## Deployment

### Railway ile Deployment
1. Railway hesabı oluşturun
2. GitHub repo'yu bağlayın
3. Otomatik deploy edilir

### Vercel ile Deployment
1. Vercel hesabı oluşturun
2. Projeyi import edin
3. Build command: `npm install`
4. Start command: `npm start`

## Notlar

- Bağlantılar 48 saat sonra otomatik olarak sona erer
- Instagram kullanıcı adı URL parametresi veya prompt ile alınır
- Tüm mesajlar ve yazım geçmişi veritabanında saklanır
